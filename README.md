# 🗺️ Simple Web GIS / Map Viewer

**Simple Web GIS** adalah aplikasi berbasis web sederhana untuk memvisualisasikan data geografis (GeoJSON) ke dalam peta interaktif. Proyek ini dibangun menggunakan Python dan HTML.

## 📂 Struktur Proyek
Repositori ini terdiri dari file-file berikut:

| Nama File | Deskripsi |
| :--- | :--- |
| `app.py` | Script Python (Backend/Server) untuk menjalankan aplikasi atau memproses data. |
| `index.html` | Halaman antarmuka web untuk menampilkan peta kepada pengguna. |
| `map.geojson` | Data spasial/geografis (koordinat wilayah/lokasi) dalam format GeoJSON. |

## 🛠️ Teknologi yang Digunakan
* **Bahasa:** Python, HTML/CSS/JS
* **Data:** GeoJSON
* **Library (Kemungkinan):** Flask (Python) atau Leaflet.js (JavaScript) untuk peta.

## 🚀 Cara Menjalankan

### Prasyarat
Pastikan Python telah terinstal di komputer Anda.

### Langkah-langkah
1.  **Clone repositori ini:**
    ```bash
    git clone [https://github.com/Zaammm16/Simple-Web-GIS.git](https://github.com/Zaammm16/Simple-Web-GIS)
    ```
2.  **Masuk ke direktori:**
    ```bash
    cd Simple-Web-GIS
    ```
3.  **Jalankan aplikasi:**
    Jika menggunakan Python biasa:
    ```bash
    python app.py
    ```
4.  **Buka di Browser:**
    Akses alamat lokal yang muncul di terminal (biasanya `http://127.0.0.1:5000` atau `http://localhost:8000`).

## 📊 Gambaran Data
File `map.geojson` berisi data vektor yang merepresentasikan lokasi atau wilayah tertentu yang akan dirender di atas peta dasar (basemap).
